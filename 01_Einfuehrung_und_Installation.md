# Leons Cozy Minecraft Modpack
## 01 – Einführung & Installation

> **Minecraft-Version:** 1.21.11 | **Mod-Loader:** Fabric  
> **Status:** Handbuch & Dokumentation

---

### 📋 Voraussetzungen

* **Minecraft Version:** 1.21.11
* **Mod-Loader:** Fabric Loader 1.21.11
* **Launcher:** Fabric-kompatibel (z. B. [Modrinth App](https://modrinth.com/app) oder [Prism Launcher](https://prismlauncher.org/))
* **Server:** Aternos Server mit Fabric 1.21.11

---

### 🌐 Downloadquellen

1. **[Modrinth](https://modrinth.com/)** *(immer bevorzugt)*
2. **[CurseForge](https://www.curseforge.com/minecraft/mc-mods)** *(nur falls auf Modrinth keine passende Version verfügbar ist)*

---

### ⚙️ Installationsreihenfolge

1. Fabric Loader installieren.
2. Minecraft einmal starten und wieder schließen.
3. Alle Bibliotheken (📦) installieren.
4. Alle Servermods (🔴) installieren.
5. Alle Clientmods (🟢) installieren.
6. Resource Packs installieren.
7. Shader installieren.
8. Aternos-Server mit den Servermods ausstatten.
9. Minecraft starten und genießen.

---

### 📁 Ordnerpfade

| Inhalt | Pfad |
| :--- | :--- |
| **Mods** | `.../.minecraft/mods` |
| **Shader** | `.../.minecraft/shaderpacks` |
| **Resource Packs** | `.../.minecraft/resourcepacks` |

---

### 🏷️ Kennzeichnungen

| Icon | Kennzeichnung | Beschreibung |
| :---: | :--- | :--- |
| 🔴 | **Host** | Zusätzlich auf den Aternos-Server installieren. |
| 🟢 | **Essential** | Muss jeder Spieler lokal auf dem Client installieren. |
| 📦 | **Bibliothek** | Wird von einer oder mehreren Mods als Dependency benötigt. |
